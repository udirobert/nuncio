# Video / live-twin upgrade

The lite first touch is text. The upgrade is a rendered personalized video
(`deliveryMode: "video"`) or a live avatar conversation link
(`deliveryMode: "livelink"`) — generated by the nuncio backend.

## Requires NUNCIO_AGENT_TOKEN

Check first: `[ -n "$NUNCIO_AGENT_TOKEN" ] && echo have-token`. Without it,
this install can only run lite mode. Tell the owner the upgrade needs a nuncio
account — create one at https://nuncio.persidian.com — and stop there. Do not
ask the owner to paste the token into chat; it belongs in the install's env.

## Render

    BASE="${NUNCIO_API_URL:-https://nuncio.persidian.com}"
    cat > /tmp/nuncio-render.json <<'EOF'
    {
      "url": "<prospect URL>",
      "senderName": "<from ~/playbook.md>",
      "senderBrief": "<brief>",
      "senderBusiness": "...", "senderOffer": "...",
      "outreachGoal": "...", "desiredOutcome": "...",
      "deliveryMode": "video",
      "autoRender": true
    }
    EOF
    curl -sS --max-time 30 -X POST "$BASE/api/agent/prospect-queue" \
      -H "Authorization: Bearer $NUNCIO_AGENT_TOKEN" \
      -H "Content-Type: application/json" -d @/tmp/nuncio-render.json

Poll `GET $BASE/api/agent/prospect-queue?id=<queueId>` (bearer header) every
~20s. Video renders take 3–8 minutes — tell the owner it's cooking and check
back, don't block the conversation.

## Result

- `result.shareId` → share page `https://nuncio.persidian.com/v/<shareId>`
  (video) or `https://nuncio.persidian.com/live/<shareId>` (live avatar).
- `result.needsReview: true` means the research was thin and render was
  skipped — tell the owner, offer to retry with a better URL.
- Give the link to the owner. Whether it goes to the prospect, and when, is
  the owner's call — log it in `~/prospects/<slug>.md`.
