# public/representative.webp / public/representative-mia.webp (+ the two loops)

The two faces in the landing hero's deck, plus the third card ("Your photo",
which is a slot rather than an asset).

Both are **stock personas from the avatar provider**, exposed to this
account's library — they are not real customers, not employees, and not
anyone's likeness being used to represent them.

- `representative.webp` / `representative-loop.mp4` — the deployment's
  default persona (the one a prospect actually meets). The loop is the
  provider's own render, trimmed to six seconds and mirrored so it loops
  seamlessly, scaled to 720×480, muted, no audio track (163 KB).
- `representative-mia.webp` / `representative-mia-loop.mp4` — another
  persona from the same library, processed the same way (99 KB).

The stills are cropped from the provider's **portrait** variant so the face
sits correctly in a circle; the landscape variant is 3:2 and loses its sides
when cropped.

Replacing them: drop a square still at each path with the face centred, and
a 16:9 (or 3:2) muted seamless loop at each `.mp4` path.
